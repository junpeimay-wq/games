# ADR-0001: 地図上の記号を選ぶクイズと学習記録

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
地図記号クイズは、利用者が実際の地図で記号を見つけ、その意味を答えながら学べる体験を提供する。記号の正誤だけでなく、どの種類を習得したかを継続して確認できる必要がある。

## 決定
- 国土地理院の最適化ベクトル地図を利用し、地図上で選択された対応済み記号の意味を4択で問う。
- 記号コードと名称の対応、および地図表示に使う記号画像名は `game-logic.mjs` で管理する。対応表にない記号はクイズ対象としない。
- 正解済み記号の一覧では、国土地理院ベクトル地図のスプライトから記号画像を取得し、記号名と一緒に表示する。
- 初回正解は100点、既知記号への正解は10点とし、不正解は学習記録に残すが得点を与えない。
- 認証済みの学習記録はFirestoreに保存し、未認証時は端末の `localStorage` を利用する。位置情報や選択場所は保存しない。
- このゲームの共通アーキテクチャ上の背景とFirestoreルールは [共通ADR-0009](../../../docs/adr/0009-local-map-symbol-quiz.md) を参照する。

## 理由
- 実際の地図記号を見ながら回答することで、記号の形と意味を結び付けて学べる。
- 図柄と名称を習得済み一覧に併記することで、過去に正解した記号を見直しやすい。
- 記録先を認証状態に応じて切り替え、Google認証をしなくても学習を続けられる。

## トレードオフ
- 記号画像は国土地理院のスプライトに依存し、スプライト名や形式が変更された場合は対応表の更新が必要である。
- `localStorage` の記録は同一ブラウザー内に限られ、認証済みデータもクライアントからの回答を完全には証明しない。
