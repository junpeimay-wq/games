# ADR-0003: 地図の初期ズームを14に固定

## ステータス
承認済み・実装済み

## 日付
2026-10-06

## コンテキスト
地図記号クイズの初期ズームは13に固定されていた。国土地理院のベクトル地図では、ズームを14にすると近隣の施設記号がより多く表示され、クイズで選べる記号も増えることを確認した。

## 決定
- 現在地周辺の地図は初期ズーム14で表示する。
- 地図の最小・最大ズームも14とし、ジェスチャーや操作による拡大縮小は引き続き無効にする。
- 地図のズーム定数は `game-logic.mjs` の `MAP_ZOOM` を利用する。

## 理由
- ズーム13よりも近隣の施設記号が見つけやすく、クイズ対象の選択肢を増やせる。
- ズームを固定し、現在地中心の操作しやすい地図レイアウトを保つ。

## トレードオフ
- ズームを上げると一度に見渡せる範囲が狭くなり、表示される記号の種類・数は地域によって異なる。
- ズーム固定のため、利用者が表示範囲を広げたり縮めたりすることはできない。

## 検証
- ブラウザーで初期ズーム、最小ズーム、最大ズームがすべて14であることを確認する。
- 国土地理院の実地図で記号が描画されることを確認する。
