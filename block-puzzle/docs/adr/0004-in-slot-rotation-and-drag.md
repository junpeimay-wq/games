# ADR-0004: 候補欄内での直接タップ回転とドラッグ＆ドロップ配置の分離

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
独立した回転ボタンによる操作は画面推移の手間が増え、候補ブロックとボタンの連動が直感的でなかった。
候補欄のブロックそのものを直接操作（回転・移動）できるように操作系を洗練させる必要があった。

## 決定
候補スロット (`.piece-slot`) の Pointer Event 判定を以下のように改善・整理する：

1. **候補欄内でのタップ（回転）**:
   - 移動量 (`dist <= 8px`) の短時間タップ/クリック時、対象のスロット内のブロックのみをその場で時計回りに90度回転させる。
   - スロット右上には回転の視覚的ヒントアイコン（🔄）を表示。
2. **候補欄からのドラッグ＆ドロップ（配置）**:
   - 移動量 (`dist > 8px`) のドラッグ時、即座にドラッグプロキシを生成して盤面グリッド上へ移動。
   - ドロップ時に中心補正位置への配置を確定。

## 理由
- 候補ブロックに触れる直感的な操作（タップ＝回転、ドラッグ＝配置）によりUIが劇的にシンプル化される。
- スマホ・タブレットのタッチ操作・PCのマウス操作双方で最小限の手数でテンポ良く遊べる。
