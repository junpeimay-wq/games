# ADR-0001: 8x8ブロックパズル（Block Puzzle）のルールと構造の定義

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
テトリスや1010!風の思考型パズルゲームとして、8x8グリッドの「8x8ブロックパズル」を新規開発する。

## 決定
以下の基本ルールおよび技術仕様を採用する：

### ゲームルール
1. **8x8盤面**: 8列x8行（計64マス）のボードグリッドを使用。
2. **ブロック生成**: 提示される3つのランダムな形状ブロック（1x1〜3x3、L字型、棒状等）から1つを選んで配置。
3. **ライン消去**: 縦または横に8マス連続で埋まるとその行/列が消去される。
4. **コンボ・複数消しボーナス**:
   - 同時に複数の行・列を消去するとボーナス点（Nライン × 100 × N）が加算される。
5. **ハイスコア保存**: IndexedDBを用いて過去最高スコアをローカル保存。
6. **ゲームオーバー判定**: 提示されたどのブロックも盤面のどこにも配置できなくなった時点でゲーム終了。

### ファイル構成
- `index.html` — 構造・スコアUI・ドラッグ/タップ選択UI
- `style.css` — 8x8グリッドレスポンシブデザイン・アニメーション
- `game.js` — グリッド判定、ブロック回転/生成、ライン消去、IndexedDB連動

## 理由
- シンプルなルールでありながら戦略性が高く、スマホ・PC両方で快適に遊べる。
- ドラッグ＆ドロップおよびタップ選択のダブル操作系をサポートし、アクセシビリティを確保。
