# ADR-0003: 直感的なドラッグ＆ドロップ操作、回転機能の導入、および1マスブロックの廃止

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
以前の配置方法は「ブロックの左上座標を指定してタップする」仕様であり、直感的ではなく操作性に課題があった。
また、ブロックの向きを変更したいというニーズや、ゲーム性のバランス調整（単体1x1マスブロックが簡単すぎる問題）があった。

## 決定
以下の機能改修を行う：

1. **ドラッグ＆ドロップ操作と中心補正**:
   - ブロックを指やマウスで直接ドラッグして盤面上へ移動・ドロップで配置する操作系へ変更。
   - 配置基準位置を左上固定ではなく、ドラッグ中のポインタ位置を中心とした相対座標補正（`hoverR - Math.floor(shape.length/2)`）により直感的な配置 preview・配置判定を行う。
2. **ブロック回転機能**:
   - 「回転 🔄」ボタンを追加し、選択中のブロック（または提示されている全ブロック）を時計回りに90度回転できるように変更。
3. **1マスブロック（1x1）の廃止**:
   - 形状テンプレートから1x1ブロック（`[[1]]`）を削除し、パズルの戦略的思考を求めるバランスに調整。

## 理由
- 直感的なドラッグ操作によりスマホ・PC双方でのUXが向上する。
- 回転機能の追加により、盤面の狭い空きマスへのハメ込み戦術が広がる。
- 1x1ブロックの削除により、難易度とゲーム性が向上する。
