# ADR-0002: はみ出し配置時の警告とキャンセル処理の導入

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
ブロックを盤面に配置する際、盤面端（8x8外）からはみ出る場所をクリックした際のエラーフィードバックが抽象的であり、ユーザーがはみ出しによる不可なのか、他ブロックとの重複による不可なのかを区別しにくい状態だった。

## 決定
配置判定ロジック `getPlacementValidity` を拡張し、無効理由（`OVERFLOW`: はみ出し、`OVERLAP`: 重なり）を明示的に判定・区別する。

### 処理フロー
1. クリック時、配置不可の理由が `OVERFLOW` の場合：
   `⚠️ ブロックが盤面からはみ出しています！配置をキャンセルしました` と警告を表示し配置を即座にキャンセルする。
2. 重複 (`OVERLAP`) の場合：
   `⚠️ 既存のブロックと重なっています！配置をキャンセルしました` と区別して表示する。

## 理由
- なぜ配置がキャンセルされたのかが明確になり、誤タップ時のユーザーの混乱を防ぐことができる。
- UXが大きく向上する。
