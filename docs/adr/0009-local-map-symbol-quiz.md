# ADR-0009: 地図上の記号を選ぶ地図記号クイズ

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
近くの施設名から地図記号を推測する方式では、利用者が地図上の記号を見つけて意味を学ぶ体験にならない。実際の地図上で記号を選び、意味を回答し、知らない記号は現地で確かめられるクイズへ変更する。

## 決定
- `terrain-quest/` は地図上の記号を選び、4択から意味を回答する「まちの地図記号クイズ」とする。標高タイル、施設名検索、Nominatim、OpenStreetMapの施設データは使用しない。
- 利用者が明示的に位置情報を許可した後、国土地理院のベクトル地図を現在地付近に表示する。地図の `Anno` レイヤーに含まれる地図記号を選択できるようにし、`vt_code` を使って記号の意味と4つの選択肢を出す。地図上の場所は国土地理院地図へのリンクで確認できる。
- 記号への初回正解は100点、すでに正解したことがある記号への正解は10点とする。不正解も回答履歴に記録するが、習得済みにはせず得点も与えない。
- Google認証済みの利用者は、`users/{uid}/mapSymbolProgress/progress` の1文書に全地図記号種別の回答数・正解数・習得状態を集約し、累計スコアをランキングに記録する。`lastUpdatedSymbol` を使って1回の更新で変更できる記号種別を1つに制限し、回答数・正解数の増分をFirestoreルールで検証する。施設・地物・座標ごとの文書は作らない。回答履歴と累計スコアはFirestoreトランザクションで更新する。未認証の利用者も、同じ種類別の記録を端末の `localStorage` に保存して得点を貯められる。認証失敗時も可能な限り端末内保存に切り替える。
- 位置情報はクライアントから地図表示先に送られるため、利用者が位置情報を許可する前に送信先を説明する。位置情報や選択した場所は学習記録・ランキングには保存しない。
- 地図記号コードと意味の対応は学習用データとして管理する。ベクトルタイルの対象コードが未対応の場合、その記号はクイズ対象にしない。地図データや記号の網羅性・分類には更新や地域差があり得ることを画面で説明する。

## 理由
- 利用者が地図上で見た記号を直接選べるため、地図と意味を結び付けて学習できる。
- 間違えた記号を現地で確かめ、改めて正解することで習得状態が記録される。
- 認証の有無にかかわらず学習と得点を続けられ、認証済み利用者だけが別端末でも記録を利用できる。

## トレードオフ
- ベクトル地図は画像タイルより選択可能な記号を扱いやすい一方、標準地図の見た目や利用可能なズーム範囲が画像タイル版と異なる。
- 地図の読み込みには国土地理院の地図スタイル・ベクトルタイルへの通信が必要で、地図範囲や位置情報が外部サービスに伝わる。
- タイル内の地物属性に依存するため、コード定義やタイル仕様の変更があればゲーム側の対応更新が必要である。
- localStorageの記録は同じブラウザー内に限られる。Firestore記録にはGoogle認証が必要で、ブラウザー側で送信される回答を完全に信頼できるものとはみなさない。
