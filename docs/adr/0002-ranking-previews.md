# ADR-0002: ランキング一覧のゲーム別Top 3表示

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
ランキングのトップページには各ゲームランキングへのリンクだけがあり、順位を見るにはゲームごとのページへ移動する必要があった。一覧性を上げつつ、採点基準の異なるゲームを合算せずに表示したい。

## 決定
- `ranking/index.html` に各ゲーム専用のTop 3を縦に並べて表示する。
- 各ゲームの専用ランキングページはTop 10まで表示する。
- 一覧の各ゲーム見出しから、そのゲーム専用のTop 10ページへ移動できる。専用ページから各ゲームへ戻る導線も維持する。
- ゲーム別ランキングの分離と採点基準については [ADR-0001](0001-game-scores-and-rankings.md) に従う。

## 理由
- トップページで全ゲームの上位プレイヤーを一覧でき、さらに詳細を見たい場合に各Top 10へ進める。
- ゲームごとに順位を保つことで異なるスコア尺度を誤って比較しない。

## トレードオフ
- トップページで最大9件のスコアを読み込むため、各ゲームの独立ページより読み取りが増える。
