# ADR-0004: ランキングへのプレイヤー画像表示

## ステータス
承認済み

## 日付
2026-10-03

## コンテキスト
ランキングデータにはGoogleアカウントから取得した `photoURL` が保存されているが、ランキング画面には表示されておらず、プレイヤーを視覚的に識別できない。

## 決定
- `ranking/` のTop 3・Top 10とFirebaseデモのランキング行に、スコアデータの `photoURL` をサムネイル表示する。
- 画像URLはHTTPSの場合だけ読み込み、参照元URLは送信しない。
- URLがない場合や画像の読み込みに失敗した場合は、共通のプレースホルダーを表示する。画像の失敗でランキングデータや順位表示は妨げない。

## 理由
- 既存のGoogleプロフィール画像を活用し、ランキング上のプレイヤーを見分けやすくする。
- HTTPSに限定し、壊れた画像や安全でないプロトコルに対して安定した表示を保つ。

## トレードオフ
- プロフィール画像はFirebase外のGoogle画像配信元へ追加リクエストを発生させる。
- ユーザーがGoogleプロフィール画像を変更した場合も、Firestoreに保存された `photoURL` は次のスコア更新まで古いままの場合がある。
