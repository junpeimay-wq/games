# ADR-0008: デザイン変更時のPRスクリーンショット証跡

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
HTML/CSSの変更はDOMやコードの差分だけでは画面上の効果や予期しない崩れを把握しにくい。レビュー担当者が変更内容を視覚的に比較できる証跡がPull Requestに必要である。

## 決定
- ユーザー向けのレイアウト、スタイル、画像表示に影響する変更を含むPull Requestには、「画面確認」セクションを設け、変更前後を比較できるスクリーンショットをPR本文に添付する。
- 変更前・変更後の画像には対象画面とビューポート（例：スマートフォン幅・デスクトップ幅）が分かるラベルを付け、比較対象の条件を揃える。
- レイアウト変更が影響する主要な画面サイズを確認し、PR本文のチェックリストに確認した幅と表示上の要点を記録する。
- スクリーンショットはGitHubのPR添付メディアとして掲載し、通常は生成画像ファイルをリポジトリに追加しない。PRにメディアを添付できない場合は理由と確認結果を明記する。

## 理由
- レビュー時に変更前後の差分と意図した見た目を迅速に判断できる。
- デスクトップでは問題が見えにくいモバイル固有の崩れなどを、変更と一緒に検証できる。
- スクリーンショットはPRレビューの証跡として保持しつつ、ソース管理へ不要な画像ファイルを増やさない。

## トレードオフ
- 画面変更ごとに複数サイズの撮影とPRへの添付が必要になり、レビュー準備に追加の手間がかかる。
- スクリーンショットは撮影時点の状態であり、実機やすべてのブラウザー環境の完全な再現を保証するものではない。
