# ADR-0013: Google認証済みユーザーのスコア端末間同期

## ステータス

承認済み・実装済み

## 日付

2026-10-11

## コンテキスト

各ゲームの未認証時の自己ベストはブラウザーのIndexedDBまたはlocalStorageに保存されるため、端末やブラウザーが変わると表示されない。Firebase AuthenticationとFirestoreには認証済みユーザーのランキングスコアが保存されているが、ゲーム本編の起動時には読み込んでいなかった。また、地図記号クイズではスコアだけでなく、獲得済み地図記号と回答履歴も端末間で引き継ぐ必要がある。

## 決定

- Googleログイン済みのユーザーは、各ゲームの起動時にFirestoreから自分のゲーム別自己ベストを読み込み、画面に反映する。
- 対象はスネーク、戦略的〇×ゲーム、8x8ブロックパズル、まちの地図記号クイズとする。
- 地図記号クイズでは、Firestoreに保存した累計スコアと記号ごとの回答履歴・習得状態を起動時に読み込む。
- 未ログイン時は従来通り端末内保存を使用する。
- Googleログインを促すタイミング、およびスコアや回答履歴をFirestoreへ記録するタイミングは変更しない。
- Firestoreに保存済みのスコアを、起動時のクラウド自己ベストとして優先する。

## 理由

- 同じGoogleアカウントでログインすれば、端末やブラウザーに依存せず自己ベストと学習記録を継続できる。
- 未ログインユーザーの既存の遊び方と端末内保存を維持できる。
- 記録処理を変更しないことで、既存の認証同意とランキング登録の挙動を維持できる。

## トレードオフ

- 未ログイン状態で端末にだけ保存されたスコアは、Googleログイン後に自動移行しない。既存の認証・記録タイミングを変えないため、移行は別の明示的な仕様として扱う。
- Firestoreの読み込み失敗時は、ゲームを継続できるよう端末内保存へフォールバックする。
- クライアントから送信されたスコアや回答の正当性を完全には証明できない。
