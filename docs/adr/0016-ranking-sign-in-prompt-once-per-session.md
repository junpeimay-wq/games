# ADR-0016: ランキング記録の確認ダイアログはセッションに1回だけ表示する

## ステータス
承認済み

## 日付
2026-11-14

## コンテキスト
[ADR-0001](0001-game-scores-and-rankings.md) では、未認証時にハイスコアを更新した場合、その都度 Google 認証が必要であることを示して記録するか確認すると定めている。

しかしこの確認がハイスコア更新のたびに繰り返し表示されると、遊びの流れが中断され、プレイヤーの離脱を招く。特にレトロ格闘ファイトのように短い試合を繰り返して連勝記録が頻繁に更新されるゲームでは、1セッション中に何度も同じ確認が出ることになる。

## 決定
- 未認証時のランキング記録の確認ダイアログは、ブラウザのセッション（sessionStorage の生存期間）につき1回だけ表示する。ゲームをまたいでも同一セッション内では再表示しない。
- 判定と記録は共通基盤（`firebase-demo/score-utils.js` の `claimRankingPrompt`）で行い、`firebase-demo/score-service.js` の `recordHighScore` が利用する。最初に確認を表示した時点で sessionStorage に記録し、以降の記録試行ではダイアログを出さずに記録を静かに見送る。
- 確認で同意して認証に成功した場合は従来どおり自動送信する。認証済みユーザーの自動記録（確認なし）も従来どおりとする。
- sessionStorage が使えない環境では、ページ読み込み中のメモリに限り1回に制限し、それも不可能な場合は従来どおり表示する（安全側のフォールバック）。
- セッションが変われば（ブラウザを閉じて再訪すれば）再び1回だけ確認する。永続的に二度と聞かない、とはしない。

## 理由
- 確認の目的は「公開ランキングに表示されること」と「Google認証が必要なこと」の事前説明であり、一度説明して判断してもらえば、そのセッション中は同じ判断が続くとみなせる。
- 毎回の確認は離脱要因になる一方、永続的な無確認化は初回の説明機会を失わせる。セッション単位がその中間として適切である。

## トレードオフ
- 一度「今回は記録しない」を選んだプレイヤーは、そのセッション中はゲーム画面から記録し直す手段を持たない（次のセッションでは再び確認できる）。
- sessionStorage はタブ単位のため、別タブで開くとタブごとに1回ずつ表示されうる。

## 関連
- [ADR-0001](0001-game-scores-and-rankings.md) の「未認証時にハイスコアを更新した場合は確認する」という規定を、本ADRが「セッションに1回まで」に改める。
