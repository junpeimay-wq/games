# ADR-0015: Progressive Web App対応

## ステータス
承認済み・実装済み

## 日付
2026-10-17

## コンテキスト
GAME ARCADEをスマートフォンやデスクトップにインストール可能にし、再訪時の表示とゲームページの利用性を向上させる必要がある。また、PWAのインストール要件を満たすため、標準サイズの正方形アイコンが必要である。

## 決定
- ルートに`manifest.webmanifest`を配置し、サイト名、テーマ色、起動URL、表示モードを定義する。
- `service-worker.js`を登録し、同一オリジンのページと静的資産をネットワーク優先で取得する。ネットワーク unavailable時はキャッシュを使用する。
- 192×192と512×512の正方形PNGアイコンを用意し、既存のアイコンとともにmanifestへ登録する。
- ゲーム、ランキング、トップページからService Workerを登録する。
- 外部地図タイルやFirebaseなど、同一オリジン外のサービスはオフラインキャッシュの対象外とする。

## 理由
- manifestとService Workerにより、主要ブラウザでインストール可能なPWAの基本要件を満たせる。
- ネットワーク優先にすることで、ゲームやランキングの更新を優先し、通信できない場合だけキャッシュへフォールバックできる。
- 192×192と512×512のアイコンを用意することで、インストール画面やホーム画面での表示品質を確保できる。
