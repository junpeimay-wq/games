# ADR-0005: mainへの変更はPull Request経由とする

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
`main` への直接Pushでは変更の確認や議論が行われないまま公開・統合される。今後は変更をPull Requestで確認してから `main` に取り込む運用が必要となった。

## 決定
- `main` に対する変更はPull Requestを作成して行う。
- 作業は `main` 以外のブランチで行い、変更内容をPull Requestとして提示する。
- Pull Requestの確認後、承認された変更をPull Request経由で `main` に取り込む。
- 直接Pushやローカルからの直接マージで `main` を更新しない。

## 理由
- `main` に入る変更を統合前に確認できるようにする。
- Pull Requestに変更の説明と議論を残し、作業履歴を追いやすくする。

## トレードオフ
- 変更を `main` に取り込むまでにPull Request作成と確認の手順が加わる。
- このADRはリポジトリの運用方針を定めるものであり、GitHub上のブランチ保護設定を自動で有効化するものではない。直接Pushを技術的に防止するには、GitHubのRulesetまたはブランチ保護設定も別途構成する必要がある。
