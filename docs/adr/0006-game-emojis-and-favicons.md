# ADR-0006: ゲーム名の絵文字とファビコンの使い分け

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
ゲーム名の装飾絵文字とブラウザーのファビコンが混同され、マルバツゲームでは横並びの `❌⭕` がページタイトルや見出しに繰り返し使われていた。前回の対応ではファビコンだけを追加し、実際に直すべき表示上の絵文字を変更していなかった。

## 決定
- ファビコンはブラウザータブやブックマーク用の独立したブランド画像とし、ページタイトルや見出しの絵文字で代用しない。ファビコンを用意する場合は正方形の専用アセットを明示的に指定する。
- 絵文字はページ名やゲームカードなど、意味を補う短いUI装飾に限る。ゲーム名の先頭には代表となる絵文字を1つだけ置き、相反する記号の横並びなど、幅を広げる重複表現を避ける。
- 戦略的〇×ゲームの代表絵文字は、プレイヤー側の〇を表す `⭕` とし、ゲーム名を表示する各ページ、カード、ランキング、デモの選択肢で統一する。
- 戦略的〇×ゲームにはこの対応で新設した専用ファビコンを残さない。過去の専用ファビコンに関するADR-0006（`tictactoe/docs/adr/0006-square-game-favicon.md`）は本ADRにより置き換える。

## 理由
- タイトル上のゲーム識別を保ちつつ、モバイルや狭いブラウザータブで横幅を抑える。
- ファビコンとページ本文の絵文字を別々の役割として扱い、誤解に基づくアセット変更を防ぐ。
- 〇はプレイヤーが操作する側の駒で、ゲームの表示上の主役を簡潔に示せる。

## トレードオフ
- 〇だけの表示では×の存在までは表せないが、ゲーム名の「〇×」表記と内容説明で補う。
- 専用ファビコンを新たに導入する場合は、ページ名の絵文字とは別にデザインと適用範囲を決定する必要がある。
