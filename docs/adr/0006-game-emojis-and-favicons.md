# ADR-0006: ゲーム名の絵文字とファビコンの使い分け

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
ゲーム名の装飾絵文字とブラウザー／検索結果のファビコンが混同され、マルバツゲームでは横並びの `❌⭕` がページタイトルや見出しに繰り返し使われていた。サイト共通のファビコンがなく、検索結果でもゲームアーケードを識別しにくい。

## 決定
- ファビコンはページタイトルや見出しの絵文字とは独立した、サイト共通のブランド画像とする。ゲームごとに異なるファビコンは設定しない。
- Google検索のガイドラインに合わせて、96×96pxの正方形PNGを `favicon.png` として配置する。URLはサイト内で安定させ、GooglebotとGooglebot-Imageが取得できるよう公開する。
- iPhoneのホーム画面追加用には同じブランドデザインの180×180px正方形PNGを `apple-touch-icon.png` として配置し、各ページから `rel="apple-touch-icon"` で参照する。
- トップページ、各ゲーム、ランキング、Firebaseデモのすべてで、同じ共通ファビコンを明示的に参照する。
- 絵文字はページ名やゲームカードなど、意味を補う短いUI装飾に限る。ゲーム名の先頭には代表となる絵文字を1つだけ置き、相反する記号の横並びなど、幅を広げる重複表現を避ける。
- 戦略的〇×ゲームの代表絵文字は、プレイヤー側の〇を表す `⭕` とし、ゲーム名を表示する各ページ、カード、ランキング、デモの選択肢で統一する。
- 過去の専用ファビコンに関するADR-0006（`tictactoe/docs/adr/0006-square-game-favicon.md`）は本ADRにより置き換える。

## 理由
- タイトル上のゲーム識別を保ちつつ、モバイルや狭いブラウザータブで横幅を抑える。
- ファビコンとページ本文の絵文字を別々の役割として扱い、誤解に基づくアセット変更を防ぐ。
- 〇はプレイヤーが操作する側の駒で、ゲームの表示上の主役を簡潔に示せる。
- 一貫したアーケード筐体の図案をサイト内すべてに表示することで、検索結果やブラウザーのタブでサイトを見分けやすくする。
- iOS向けのホーム画面アイコンを明示することで、ページのスクリーンショットが代用されるのを防ぎ、追加後も正方形アイコンとして表示する。

## トレードオフ
- 〇だけの表示では×の存在までは表せないが、ゲーム名の「〇×」表記と内容説明で補う。
- Googleはサイトごとに1つのファビコンを選択し、正方形のアイコンを再クロール後に検索結果へ反映する。GitHub Pagesのプロジェクトサイトはホスト名のサブディレクトリ（`/games/`）にあるため、ホスト単位のGoogle検索ファビコンとして必ず採用される保証はない。また、Googleが表示するか、いつ更新するかは制御できない。
