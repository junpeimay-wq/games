# ADR-0004: MITライセンスの採用

## ステータス
承認済み

## 日付
2026-09-20

## コンテキスト
公開GitHubリポジトリにライセンスが明示されていなかった。
ライセンス未記載の場合、著作権は著作者に帰属したままとなり、
第三者はコードのコピー・改変・再配布が法的に行えない状態だった。

## 決定
MITライセンスを採用する。

## 理由
- 個人OSSの標準的な選択肢であり、広く認知されている
- 使用・改変・商用利用・再配布を自由に許可しつつ、著作者表示のみ要求する
- ゲームのポートフォリオとして広く公開・参照されることを歓迎するため、制限の少ないライセンスが適切
- CC0（パブリックドメイン）と異なり、著作者クレジットが残る

## トレードオフ
- 商用利用を制限したい場合にはCC BY-NC等が適切だが、今回は制限不要と判断
- コードを利用した側がMITライセンスの著作者表示義務を遵守するかは利用者次第
