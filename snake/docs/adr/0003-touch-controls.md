# ADR-0003: スマホ・タブレット向けタッチ操作の追加

## ステータス
承認済み

## 日付
2026-09-20

## コンテキスト
初期実装はキーボード操作（矢印キー・WASD）のみ対応していた。
スマホ・タブレットなどキーボードなしのデバイスでもプレイできるようにする必要があった。

## 決定
以下の2つのタッチ操作方式を並行して実装する：

1. **スワイプ操作**：Canvas上でのタッチ開始・終了座標の差分から方向を判定
2. **画面上の方向ボタン（Dpad）**：▲◀▼▶ の4ボタンをCanvas直下に配置

## 理由
- スワイプは直感的だが、誤操作が起きやすい場面がある
- 方向ボタンはゲームパッド感覚で確実に操作できる
- 両方提供することでユーザーが好みの方法を選択できる
- ライブラリ不要でTouch Events APIのみで実装できる

## 実装詳細
- `touchstart` で開始座標を記録
- `touchend` で終了座標との差分（dx・dy）を比較し、大きい軸の正負で方向を決定
- 移動量が10px未満の場合はタップと判定し、ゲームスタートに使用
- `touch-action: none` と `passive: false` でスクロールのデフォルト動作をキャンセル

## トレードオフ
- 方向ボタンがCanvasの下に追加されるため、小さい画面では縦スクロールが必要になる場合がある
- スワイプの感度（10pxしきい値）は固定値のため、デバイスによって調整が必要になる可能性がある
