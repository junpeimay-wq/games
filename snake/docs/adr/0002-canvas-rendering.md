# ADR-0002: 描画にCanvas APIを採用

## ステータス
承認済み

## 日付
2026-09-20

## コンテキスト
ゲームの描画方式として以下の選択肢があった。
- DOM操作（divを動かす）
- Canvas API
- WebGL

## 決定
Canvas APIを採用する。

## 理由
- ライブラリ不要でブラウザ標準APIのみで完結する
- スネークのようなグリッドベースゲームに十分なパフォーマンス
- DOMより描画コードがシンプルになる
- WebGLは今回の規模では過剰

## トレードオフ
- Canvas内の要素はDOMとして操作できない
- アクセシビリティ対応が必要な場合は別途考慮が必要
