# ADR-0001: 単一HTMLファイル構成からファイル分離構成へ

## ステータス
承認済み

## 日付
2026-09-20

## コンテキスト
ブラウザゲームの初期開発において、最短時間でプロトタイプを動かすことを優先した。
HTML/CSS/JSを1ファイルにまとめることで即座に動作確認ができたが、
コードの可読性・保守性を向上させるためにファイル分離を検討した。

## 決定
`index.html`・`style.css`・`game.js` の3ファイルに分離する。

| ファイル | 責務 |
|---------|------|
| index.html | 画面構造（HTML） |
| style.css | 見た目・レイアウト |
| game.js | ゲームロジック |

## 理由
- 各ファイルの変更差分が役割単位で明確になる
- CSSだけ・JSだけの変更をgit上で追跡しやすくなる
- 将来的なゲームの追加・共通スタイルの切り出しが容易になる

## トレードオフ
- ローカルでは `file://` プロトコルでは動作しなくなる（HTTPサーバーが必要）
- ファイル数が増えるため、GitHub Pagesのような静的ホスティングが前提となる
