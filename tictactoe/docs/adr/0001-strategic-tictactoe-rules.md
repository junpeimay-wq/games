# ADR-0001: 戦略的〇×ゲームの基本ルールと構造の定義

## ステータス
承認済み

## 日付
2026-10-02

## コンテキスト
通常の〇×ゲーム（Tic-Tac-Toe）は引き分けになりやすく、戦術的な深みが少ない。
ゲーム性を高めるために、相手の駒の上書きルールを追加した「戦略的〇×ゲーム」を新規開発する。

## 決定
以下の基本ルールと構成を採用する：

### ゲームルール
1. 3x3のグリッドを使用する。
2. プレイヤーは先手（〇）、CPUは後手（×）。
3. 空きマスへの配置は無制限。
4. **上書きルール**: 相手の駒の上に対して最大2回まで上書き（〇は×の上、×は〇の上）できる。
5. 縦・横・斜めのいずれかに3つ自分の駒を並べた方が勝利。

### ファイル構成
- `index.html` — 画面構造とUI要素のみ
- `style.css` — レスポンシブ対応・モダンデザイン
- `game.js` — ゲーム状態管理、勝敗判定、CPUアルゴリズム

## 理由
- 上書き回数（各2回）の制限により、タイミングや盤面コントロールの戦術が生まれる。
- 標準Web技術（HTML/CSS/JS）のみで実装し、モバイルタッチ操作にも対応する。
