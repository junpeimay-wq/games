# ADR-0002: アグレッシブなCPU思考アルゴリズムへの強化

## ステータス
承認済み

## 日付
2026-10-02

## コンテキスト
初期のCPUアルゴリズムは空きマスへの配置を優先しており、プレイヤーの上書き権限に比べてCPUの上書き利用が消極的で「弱すぎる」という問題があった。
手応えのあるゲーム体験を提供するため、CPUの思考アルゴリズムを強化する。

## 決定
スコア評価ベースの戦略的CPUアルゴリズム（Evaluator Algorithm）を導入する。

### 主な評価基準
1. **即時勝利 (+10000)**: 空きマスまたはプレイヤーの〇を上書きして3連をつくれる場合、最優先で実行。
2. **王手阻止 (+5000)**: プレイヤーが次手で勝利するラインを検出した場合、空きマス配置または〇の上書きで確実にブロック。
3. **積極的属性ボーナス (+300~+450)**:
   - プレイヤーが配置した中央（インデックス4）や重要ラインの〇を積極的に上書き奪取する。
   - 上書きによって自身のリーチ（2連）を構築する手を高評価。
4. **標準戦術点**: 中央(+200) > 角(+100) > 辺(+40)

## 理由
- プレイヤーの駒を積極的に奪うことで、ゲーム展開に緊張感が生まれる。
- スコア評価型アルゴリズムにより、最善手および次善手を動的に算出できる。
