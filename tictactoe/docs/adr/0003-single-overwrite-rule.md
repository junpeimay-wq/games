# ADR-0003: 上書き上限回数を1回に変更

## ステータス
承認済み

## 日付
2026-10-02

## コンテキスト
上書き回数を2回とした場合、お互いに盤面を大きく書き換えることができすぎ、1回ごとの上書きの価値や切り札としての重要性が薄れる傾向があった。

## 決定
上書き回数の上限を各プレイヤー「**1回のみ**」に変更する。

## 理由
- 上書きカードを「唯一の切り札」として温存・使用するタイミングの駆け引きがよりシビアになり、ゲームの緊張感が増す。
- 1回使い切ると再上書きができないため、CPU・プレイヤー双方にとって使い所が重要なゲームバランスになる。
