# ADR-0006: 〇×ゲームの正方形ファビコン

## ステータス
承認済み

## 日付
2026-10-04

## コンテキスト
〇×ゲームにゲーム固有のファビコンが設定されておらず、ブラウザーの表示が統一されていない。ゲームのシンボルを横並びにしたような横長の表示では、小さなタブ上で見栄えと識別性が悪い。

## 決定
- 〇×ゲーム専用のファビコンとして、正方形のSVGアイコンを用意する。
- 暗色の正方形の盤面に〇と×を配置し、ゲーム画面の配色と合わせる。
- ゲームのHTMLからこのSVGを明示的にファビコンとして読み込む。

## 理由
- ファビコンの正方形の表示領域を使い、ブラウザーのタブやブックマークでもゲームを識別しやすくする。
- SVGを使うことで、高密度・高解像度の画面でも鮮明さを保ち、複数サイズの画像を管理せずに済む。
