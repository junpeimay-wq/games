# ADR-0006: 〇×ゲームの正方形ファビコン

## ステータス
置き換え済み（[共通ADR-0006](../../../docs/adr/0006-game-emojis-and-favicons.md)）

## 日付
2026-10-04

## コンテキスト
〇×ゲームにゲーム固有のファビコンが設定されていないと誤認し、ページタイトルに表示されていた `❌⭕` をファビコンと取り違えた。

## 決定
- 誤解に基づき、〇×ゲーム専用の正方形SVGファビコンを追加する。
- 本決定は[共通ADR-0006](../../../docs/adr/0006-game-emojis-and-favicons.md)により置き換えられた。ページ名の絵文字とファビコンを別の要素として扱い、このSVGファビコンを削除する。

## 理由
- （置き換え済み）前回の対応は、ユーザーが変更を希望したページ名の絵文字に対応していなかった。
