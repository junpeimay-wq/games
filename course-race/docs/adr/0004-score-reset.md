# ADR-0004: 難易度見直しに伴うベストスコアのリセット

## ステータス
承認済み

## 日付
2026-11-25

## コンテキスト
ADR-0003 の難易度見直しにより、新ルールの上限スコア（合計およそ 2,700 点前後）が旧ルールの記録（オーナーの 7,795 点など）を下回った。旧記録が残ると新ルールでは二度と更新できないベストが表示され続けるため、オーナーの判断でベストスコアを一度リセットすることにした。

## 決定
- 端末内のベスト（合計とコース別）は、保存キーを `course-race-best-score-v2` / `course-race-stage-bests-v2` に切り替えてリセットする。旧キーは読み込まない（保存コースのキーはスコアではないため変更しない）。
- クラウドのスコア文書は、Firestore ルールが「より高いスコアへの更新」だけを許可し、クライアントからの削除も許可していないため、コードからはリセットできない。対象の文書（`scores/course-race_<uid>`）はオーナーが Firebase コンソールから手動で削除する。
- 他のゲームのスコアには影響しない。

## 理由
- キーの versioned 切り替えは、全端末で一斉に・確実にリセットでき、利用者側の操作（キャッシュ削除など）が不要。
- スコア文書の削除権限をクライアントに与えない現行ルールは不正対策として維持する。リセットは滅多に起きないため、コンソールでの手動削除で足りる。

## トレードオフ
- 旧キーに残ったデータは端末に残置されるが、読み込まれることはない。
- ランキングに他のプレイヤーの旧ルール記録がある場合、その削除もコンソールでの手動対応になる（削除するかどうかはオーナーが判断する）。
